# Learning Linux by Gene Family Bioinformatics Analysis
这篇文章旨在为大家撰写生物信息学基因家族分析方向的毕业论文提供一些指导。

本教程的核心教学目标是Linux的使用：

- 若你并不想接触编程，可重点参考教程的整体框架，了解完成基因家族分析需要借助其他软件执行哪些核心步骤。
- 若你希望学习使用 Linux 分析数据，本教程将极具实用价值。尤其适合有基因家族分析经验，但不熟悉 Linux 的人群——你或许清楚基因家族分析的完整流程，此前却主要使用 TBtools、Mega12 等图形界面软件，很少亲自运行代码，这份教程正是为你量身打造。

本教程最大的特点是零基础友好：我们默认你不具备任何编程基础，无论是 R 语言、Python 还是 Linux，都将从最基础的内容讲起。我们会以极度详细的方式，一步步拆解每一个操作细节——毕竟在生物信息学入门阶段，最困难的往往不是分析数据本身，而是连软件都无法成功安装。

针对软件安装这一入门痛点，我们会教授多种方法：既会讲解最传统、也最具挑战性的源代码编译安装方式，也会介绍生物信息学软件的“大管家”——Anaconda，通过两三行代码即可轻松完成软件部署。在代码编写过程中，我们会详细解释代码的设计逻辑；在文件选取环节，也会明确说明选择这些文件的原因。总而言之，我将自己能想到的、初学者可能遇到的所有问题和疑问，都一一记录并解答在这份教程中。

这份教程不仅是写给正在入门的你们，更是写给当年那个无助的自己。在 AI 时代尚未完全普及的过渡期，我曾在生物信息学的门槛前摸爬滚打，靠着上网搜索和向 AI 请教，才慢慢摸清了入门的门路。

本教程并无代码层面的创新——这些基础代码都能轻松获取，我所做的创新，是将基因家族分析的全流程集成整合，并尽可能通过 R 语言实现所有可视化图表的绘制（不得不说，R 制作的图表效果真的非常出色）。

希望这份小小的教程，能帮助更多人顺利踏入生物信息学的大门，这也是作为一名生物信息学学子，我最感骄傲的事情。

## 阅读导航

第一次访问建议按以下顺序阅读：

1. [完整教程](A_Tutorial_For_Linux_Learning.md)：保留原有的详细讲解与操作示例。
2. [学习路线与章节索引](docs/learning-path.md)：按分析阶段查找章节，区分已有内容与待补充内容。
3. [文件说明与运行约定](docs/usage.md)：了解脚本输入输出、依赖和工作目录。
4. [已知问题与后续完善](docs/known-issues.md)：运行前查看示例限制及尚未验证的环节。

本仓库以苹果等植物的 GALT 家族为案例，通过实际分析学习 Linux。它是一份教学教程，部分步骤需要手动筛选、使用在线工具或准备额外数据，目前还不是一键运行的完整分析流程。

## 仓库目录

```text
.
├── README.md                         # 项目介绍与导航
├── A_Tutorial_For_Linux_Learning.md   # 完整教程（保留原入口）
├── docs/                             # 学习路线、使用说明、已知问题
├── scripts/
│   ├── shell/                        # 下载整理与家族鉴定脚本
│   ├── python/                       # 蛋白性质与 GFF 转换脚本
│   └── r/                            # 结构图绘制与 Circos 数据转换
├── config/                           # 数据下载清单与共线性配置模板
├── data/
│   ├── reference/                    # 参考蛋白与 HMM 模型
│   └── examples/                     # 示例 ID、重命名表与结构域结果
└── identification.zip                # 保留的旧版教学压缩包
```

`data/` 中是教学参考文件，不包含运行整个流程所需的全部基因组数据。建议将下载数据和分析结果放在独立工作目录，具体准备方式见[运行约定](docs/usage.md#准备分析工作目录)。旧压缩包保留原样，不会自动同步目录中的脚本。
