## 脚本运行限制

- 下载脚本逐行读取清单，未跳过注释和空行；使用 `tar -av *.zip`，需要修正 ZIP 解压步骤；下载或重命名失败后仍可能打印成功信息。
- 下载清单中没有与 DNA / GFF 对应的拟南芥全蛋白下载项；`ath.galt.pep` 是查询序列，不能替代拟南芥全蛋白文件。
- 鉴定脚本默认 GALT / PF01762、BLAST E-value 为 `10`，并使用 HMM 与 BLAST ID 的交集。这些是原案例参数，换家族时需要重新评估。
- 鉴定脚本末尾会执行 `rm *.zip`；输出目录需事先存在；脚本缺少完整的失败中止和空输入处理。
- 两版 R 绘图脚本使用固定文件名，并尝试安装缺失依赖；仓库不包含其安装逻辑所需的 `ggmotif_0.2.1.tar.gz`。
- GFF 转换脚本按 ID 中的点号截断并补 `.1`，用类型列排序，用坐标推导长度表。这些假设需要结合目标注释格式和下游工具要求复核，不能作为通用转换器。
- `identification.zip` 是历史快照，内部脚本具有相同的旧版限制，且不会随源码自动更新。
